# Network Management

This repository contains my networking activities and assignments focused on **Cisco Packet Tracer simulations**. It showcases practical implementations of networking concepts, configurations, and troubleshooting scenarios.

The goal of this repository is to document my progress in networking, strengthen my understanding of infrastructure design, and build a solid foundation for real-world network environments.

## Contents

* **Packet Tracer Files (.pkt)** – Network simulations and lab activities
* **Configurations** – Router, switch, and device setups
* **Topologies** – Different network designs and layouts
* **Assignments** – Academic and practice-based exercises

## Features

* **Hands-on Networking Labs**
  Real-world inspired simulations using Cisco Packet Tracer
* **Structured Learning**
  Organized activities from basic to more advanced networking concepts
* **Configuration Practice**
  Includes CLI configurations for routers, switches, and end devices
* **Troubleshooting Scenarios**
  Exercises focused on diagnosing and fixing network issues

## Topics Covered

* Network Topologies
* IP Addressing & Subnetting
* VLAN Configuration
* Routing (Static & Dynamic)
* Switching Concepts
* DHCP, DNS, and Basic Services
* Network Troubleshooting

## Tools Used

* **Cisco Packet Tracer** – Network simulation and visualization
* **CLI (Command Line Interface)** – Device configuration
